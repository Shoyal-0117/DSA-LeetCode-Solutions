# DSA — LeetCode Solutions

A structured collection of my **LeetCode solutions** focused on DSA mastery, coding interviews, and placement preparation.

## 🎯 Objectives

* Strengthen DSA fundamentals and problem-solving skills
* Prepare for coding interviews and placement OAs

* Improve time and space complexity
* Maintain concise notes for revision

## 📂 Repository Structure

Each problem contains:

* **`solution.cpp`** — Latest accepted solution
* **`question.md`** — Problem statement and relevant metadata
* **`notes.md`** — Intuition, key observations, complexity, mistakes, and revision points
* **`approaches/`** — Important alternative approaches preserved separately
